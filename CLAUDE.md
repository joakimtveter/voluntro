# Voluntro

## Project

- Architecture and agreed decisions: `docs/architecture/overview.md`. Read it before planning or reviewing any work.
- The developer writes all application code themselves, to build their skills. Don't write or change application code unless they explicitly ask you to implement a feature or part of one. Otherwise help with design, questions, reviews and planning.
